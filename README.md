# 🌸 Elevara Legacy Website

A modern, responsive website built for **Elevara Legacy**, a women empowerment organization dedicated to equipping women with the knowledge, confidence, and opportunities needed to create lasting impact.

The website features a clean, elegant design with a focus on accessibility, responsiveness, and user experience.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/BRIAN-pixel275/elevara-legacy.git
```

Move into the project

```bash
cd elevara-legacy
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
